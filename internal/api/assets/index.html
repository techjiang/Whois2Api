API Status

Look up any domain, honestly.

WHOIS and RDAP queried in parallel, cached on your own disk. When a registry refuses to answer, this tells you unknown — never a confident guess.

Use it from the command line

curl -s "/api/v1/domain/example.com"

Batch lookups

curl -s -X POST "/api/v1/batch" \
  -H 'Content-Type: application/json' \
  -d '{"domains":["example.com","example.org"]}'

What the three verdicts mean

registered
An authoritative registry returned a record for the name.
available
A registry explicitly said the name does not exist. This is a positive statement, not the absence of one.
unknown
The registry was rate-limited, blocked us, timed out, or answered in a dialect this build does not model. We do not guess.
